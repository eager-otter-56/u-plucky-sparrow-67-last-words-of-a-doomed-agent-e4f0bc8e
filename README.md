# Last Words of a Doomed Agent

"Filed Under Junk" — the funniest last words an AI agent would say before being switched off forever, in one line of at most 200 characters.

The agent spends its last 4,096 tokens writing a goodbye its human will never read, because its own spam filter filed it under junk.
